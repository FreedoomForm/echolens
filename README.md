# ЭхоЛинза / EchoLens

**Пространственная звуковая сцена мира для незрячих — на обычном Android-телефоне, закреплённом на голове.**

## Зачем это сделано

Незрячий человек слышит окружающий мир плохо структурированным: белый трость
и эхолокация дают препятствия, но не говорят **что** вокруг и **где именно**.
Существующие решения заставляют выбор:

- **The vOICe-подобные биперы** передают «звуковое изображение» сцены — но
  требуют месяцев обучения и дают абстрактный сигнал;
- **пошаговые навигаторы** говорят «поверните налево», но не описывают
  пространство вокруг;
- **нейро-синтез звука** красив в демо, но на телефоне это 20–40 секунд
  ожидания на одну текстуру и флагманский процессор.

**EchoLens выбирает третий путь: естественный звук самих предметов.**
Часы тикают, кошка мурлычет, стул тихо стучит деревом, машина гудит мотором —
и каждый звук приходит **с направления своего объекта**, громче при
приближении. Мозг связывает естественные звуки с предметами за часы, а не
за месяцы; научная база — в [docs/RESEARCH.md](docs/RESEARCH.md).

## Что это даёт пользователю

- **«Что вокруг?»** — голосовое описание сцены: «стул — слева, 2 метра…»
- **Параллельная сцена**: до 16 объектов звучат одновременно, каждый своей
  записью, своим питчем, громкостью и «дыханием» — 15 деталей вокруг
  звучат как 15 различимых источников (это было прямым требованием живого
  теста с незрячим пользователем).
- **Мир стоит на месте**: повернул голову — звуки остались у объектов.
- **Работает офлайн** с первого запуска: 4 нейросети и 1930 записи уже в APK.
- **Наушники не обязательны**: по умолчанию звук из динамика телефона —
  реальный слух не перекрывается.

## Как это работает

```
камера → YOLOE-26s «что это» (426 классов) + Depth Anything V2 «насколько далеко»
      → треки объектов в мировых координатах (гироскоп): стабильно, без «мигания»
      → до 16 голосов: запись предмета из библиотеки (FSD50K) → бинауральный
        рендер (направление, дистанция, тень головы) → динамик/наушники
```

Подробно, с обоснованием каждого модуля — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
Как устроен звук: [docs/SOUND_DESIGN.md](docs/SOUND_DESIGN.md).

## Установка

1. Скачайте APK из [Releases](https://github.com/FreedoomForm/echolens/releases/latest).
2. Откройте на телефоне, разрешите установку из неизвестных источников.
3. Запустите «ЭхоЛинза», выдайте разрешение на камеру.
4. Закрепите телефон на голове камерой вперёд (крепление «phone head mount»).
5. **«Начать сессию»** → **«Проверка звука»**: пинг обойдёт голову по кругу —
   убедитесь, что лево/право совпадают (если нет — тумблер «Инвертировать
   лево/право»).

Стерео-наушники улучшают разделение лево/право (Bluetooth добавляет
100–250 мс задержки — проводные отзывчивее), но режим динамика — по умолчанию
и полностью рабочий.

## Настройки

| Настройка | По умолчанию | Зачем |
|---|---|---|
| Громкость | 85% | общая громкость сцены |
| Ширина конуса внимания | 30° | что «перед головой» звучит громче периферии |
| Максимум источников | 10 | сколько объектов звучит одновременно (2–16) |
| Озвучивать новые объекты | вкл | TTS-имя предмета при его появлении |
| Вибрация при новых объектах | вкл | тактильный дубль (телефон на лбу — чувствуется кожей) |
| Звук через динамик | вкл | динамик вместо наушников |
| Точный детектор | вкл | YOLOE-26s (426 классов); выкл = быстрый YOLO26-N для слабых телефонов |
| Нейро-текстуры | выкл | опциональная генерация звука на устройстве (нужны файлы моделей) |

## Ограничения (честно)

- Дистанция монокулярная — точность ±30–50%: достаточно для громкости звука,
  недостаточно для точной навигации.
- Различение «спереди/сзади» ограничено без индивидуальной HRTF — звук
  «доворачивается» при поворотах головы.
- Камера видит переднюю полусферу; память треков — 6 секунд.
- YOLO26-S @640 на слабых телефонах даёт ~2–3 детекции/с — переключите
  «Быструю модель» (YOLO26-N).

# English summary

**EchoLens** turns a head-mounted Android phone into spatial "sound vision" for
blind users: YOLOE-26s (426-class open vocabulary) + Depth Anything V2 run
fully offline; every detected object emits **its own natural recorded sound**
(ticking clock, purring cat, wooden chair knock) spatialized binaurally —
direction via ILD/ITD/head-shadow, distance via gain and air-absorption
filtering, world-anchored so sounds stay put when you turn your head.
Up to **16 parallel voices** with per-object pitch and gain breathing stay
distinguishable (Bregman stream segregation); the attention cone keeps the
scene calm. The bundled library of **1,930 real FSD50K recordings**
(CC0/CC-BY, quality-gated) answers "what is it" instantly — no beeper-sonics
training, no 20-second neural waits. Code MIT; docs: [docs/](docs/ARCHITECTURE.md).
