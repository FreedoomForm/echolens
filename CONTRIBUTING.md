# Contributing to EchoLens

Спасибо за интерес к проекту! Цель EchoLens — доступное пространственное
звуковое восприятие для незрячих на обычном Android-телефоне.

## Как помочь

- **Живые тесты**: описание бага (телефон, Android-версия, что звучало,
  что ожидалось) в Issues — самый ценный вклад, устройство у вас.
- **Код**: файлы → `app/src/main/java/com/echolens/app/`; назначение каждого
  модуля — `docs/ARCHITECTURE.md`.
- **Звуки**: кандидат-записи для классов без набора — см.
  `docs/SOUND_DESIGN.md` и `docs/DEVELOPMENT.md`.
- **Исследования**: если знаете работу, меняющую проектные решения, —
  `docs/RESEARCH.md` живёт ссылками.

## Правила

1. Перед PR: `./gradlew testReleaseUnitTest assembleRelease` — зелёные.
2. Каждый модуль/константа с нетривиальной мотивацией — с KDoc «почему».
3. Сторонние модели/данные — только с лицензией, совместимой с MIT-кодом
   приложения; записи — CC0/CC-BY с атрибуцией (`THIRD_PARTY_LICENSES.md`).
4. Один PR = одна тема; описание отвечает на вопрос «зачем».
5. Коммиты: `vX.Y.Z: ...` — только релизные; остальные — `область: что сделано`.

## Сообщения о проблемах безопасности

См. [SECURITY.md](SECURITY.md) — не публикуйте уязвимости в публичных Issues.
